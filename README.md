📌 Project Overview
This project was completed as part of the Deloitte Australia Data Analytics Virtual Experience Program on Forage.  
The simulation focused on analyzing structured business data, identifying data quality issues, and delivering actionable insights through visualization and business reporting.

The objective was to simulate real-world data analytics tasks performed in a consulting environment.

🎯 Key Objectives
- Perform data analysis using Excel
- Identify data inconsistencies and business insights
- Build an interactive Tableau dashboard
- Present findings in a structured, stakeholder-friendly format

🛠 Tools & Technologies
Microsoft Excel - (Pivot Tables, Formulas, Data Cleaning)
Tableau - (Data Visualization & Dashboard Development)
Business Reporting

📊 Project Tasks & Work Completed

 1️⃣ Data Analysis & Cleaning
- Reviewed structured business datasets
- Identified data quality issues and inconsistencies
- Applied sorting, filtering, pivot tables, and formulas
- Structured data for analysis-ready reporting

2️⃣ Data Visualization
- Designed an interactive Tableau dashboard
- Visualized key operational trends and performance metrics
- Transformed raw data into clear visual insights

3️⃣ Business Insight & Reporting
- Interpreted analytical findings
- Developed business recommendations based on insights
- Communicated results in a professional summary presentation

📈 Key Skills Demonstrated
- Data Cleaning & Validation  
- Exploratory Data Analysis (EDA)  
- Dashboard Development  
- Data Storytelling  
- Business Insight Communication  
- Stakeholder-Focused Reporting
